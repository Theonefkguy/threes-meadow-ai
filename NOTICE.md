This is an independent research implementation. Threes! is a game by Sirvo; this project is not affiliated with or endorsed by Sirvo. The supplied project's rule documentation states that official artwork, audio and character assets are not used. Model files are the supplied project's trained N-tuple weights, not downloaded third-party model weights.

## Research and rule references

- [Kamikaze28 & ekisacik, Basic & Advanced Secrets of Threes! (2024)](https://steamcommunity.com/sharedfiles/filedetails/?id=3155431026): community reconstruction of card selection and placement.
- [nneonneo/threes-ai](https://github.com/nneonneo/threes-ai/tree/c554820ad848a73b7cd34e358c974ab2d85bd792): reference implementation used for rule comparison; not bundled as an external dependency. The optional V20 comparison script needs a separately installed copy.
- [rilka/threesjs](https://github.com/rilka/threesjs): movement and spawn behavior reference listed in the original project documentation.
- [Yeh et al., Multi-Stage Temporal Difference Learning for 2048-like Games (2016)](https://arxiv.org/abs/1606.07374): multi-stage TD learning and historical Threes evaluation.
- [Jaskowski, Mastering 2048 with Delayed Temporal Coherence Learning… (2016)](https://arxiv.org/abs/1604.05085): temporal coherence and related training ideas.
